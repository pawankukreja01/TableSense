# Pilot evaluation
Start with one independent waiter-served restaurant and 8–20 tables. Obtain sign-off on item costs, prices, relevant pairings and the staff workflow. Record device purchase/setup, charging, cleaning, support, replacement and subscription assumptions separately.

1. Run a dry service. Confirm Table 07 isolation, display quiet/expiry/dismissal/reset, unavailable menus, Wi-Fi loss/reconnection, browser restart, battery reporting and actual kiosk controls. Assign a duty manager to withdraw stock and review allergens.
2. Choose control allocation before the experiment (e.g. 50%). Keep it stable during evaluation. Assign by anonymous visit and retain the assignment, including visits with no exposure. Count eligibility consistently in both arms. Avoid selective manual capture for “promising” parties.
3. Agree an outcome window and a recording process that captures *all* comparable fulfilled add-ons in both cohorts, including unaided sales in control. Match item-level receipts, returns, discounts and variable costs to visit IDs using an approved reconciliation process. An impression, a verbal request and a staff mark are separate signals. None establishes causality alone.
4. Compute each cohort’s sum of actual add-on contribution (net selling price less variable costs) divided by all eligible sessions in that cohort, including zeros. Subtract control from treatment. Report sample sizes, missing matches, uncertainty and differences by shift; consider repeated-table/shift correlation. Do not compute uplift from treated suggestions alone. The built-in report leaves this metric unavailable.
5. Track manual capture time, skipped signals, guest opt-outs and voluntary anonymous comments, device interruptions, battery at close, cleanup time and any table that had to operate without a screen. Collect observations in both arms; use the staff report field without names.
6. Compare contribution after operational cost with the one-time hardware price and recurring software charge. Decide acceptable thresholds and study length with the venue before viewing outcomes. If POS capture is unreliable or guests find screens disruptive, address that before expanding.
